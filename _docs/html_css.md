# HTML & CSS Learning Roadmap

## 1. Forms & Inputs
* **Form Container**: `<form>`
* **Text Inputs**: `<input type="text/email/password">`
* **Buttons**: `<button>`, `<input type="submit">`
* **Labels**: `<label>`
* **Textarea**: `<textarea>`
* **Checkboxes**: `<input type="checkbox">`
* **Radio Buttons**: `<input type="radio">`
* **Dropdown Menus**: `<select>` and `<option>`

## 2. Semantic HTML & Layout Structure
* **Header & Footer**: `<header>`, `<footer>`
* **Navigation**: `<nav>`
* **Main Content**: `<main>`
* **Sections & Articles**: `<section>`, `<article>`
* **Sidebar**: `<aside>`

## 3. Tables & Media
* **Tables**: `<table>`, `<tr>`, `<td>`, `<th>`
* **Audio & Video**: `<audio>`, `<video>`
* **Embedded Content**: `<iframe>`

## 4. CSS Essentials for Layout & Styling
* **Selectors**: Class, ID, and Tag selectors
* **Box Model**: Margin, Padding, Border, Width, and Height
* **Colors & Typography**: Text colors, Backgrounds, and Fonts
* **Layout Systems**: Flexbox and CSS Grid
* **Interactions**: Hover effects (`:hover`) and CSS Transitions
